# Surface brief: game shell (menu + play screen)

## Scope and visitor mode

Experience. The artifact is the game itself: menu, play screen, results slip, end modal. The arena canvas is the lead; interface recedes.

## Audience, job, action

Casual web gamers on desktop and mobile. They must be playing within seconds, understand the loop without reading, and retry a run in one action. Success is engagement and continuous play.

## Pinned direction

THESIS: the entire screen is the cardboard playfield; the laser lives on it wall to wall, and a handful of light HUD marks float on top

OWN-WORLD: the canvas fills the whole viewport and IS the arena: cardboard texture edge to edge, laser bouncing off the screen edges, paper-ball targets sitting on the cardboard; ink navy line work; laser red-orange as the only saturated accent; the UI is a minimal HUD of light marks overlaid directly on the playfield (small paper scraps, tape tags, stamped numerals, one floating action button, one quiet icon cluster), never bars or panels; large type (minimum 14px UI text, labels 12px only when unavoidable); drawn SVG icons in one stroke weight; no emoji, no kickers, no decorative meta text.

STORY: the visitor lands on the cardboard with the title, a mode switch, a difficulty slider, one big play action, a run code field and nothing else. In-game, the eye stays on the arena: page, mistakes, ink, and score read as large numerals at the screen edge; phase changes are communicated by the canvas (countdown arc, blink, beam), not captions. Right-click or Space advances the page: skip the study window, fire, turn the page. A page that is not fully burned shows the expected path in blue pencil under the red beam. Run end offers replay-same-code, new run, menu.

FIRST VIEWPORT: the whole viewport is the cardboard playfield with the turret and targets on it. Menu overlays on the same fullscreen arena: oversized LaserBlink title, Notebook/Endless switch, a difficulty slider, one big play button, run code field, quiet corner icon cluster. Nothing else. In game: page, mistakes, score, and ink are small HUD marks at the screen edges; one floating action button (Aim / Fire / Next page / Finish); countdown lives in the canvas ring. No prose anywhere.

FORM: pinned by the user (dark surround + paper arena + minimal text). seed: none (pinned) "Keep the paper/scratchpad arena look, but darken everything around it", "remove all kickers and useless stuff", "use bigger text".

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
